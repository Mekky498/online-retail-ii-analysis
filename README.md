# Online Retail II - Power BI Interactive Dashboard

An end-to-end business intelligence and data analytics solution analyzing transaction, customer, and product metrics using Power BI.

---

## 📊 Dashboard Pages & Insights
* **Overview:** High-level executive KPIs, net revenue trends, and regional performance.
* **Customer Overview:** Customer retention analysis, repeat customer rates, and active customer trends.
* **Product Overview:** Top 10 SKU revenue generators, units sold trajectory, and credit memo return rates.
